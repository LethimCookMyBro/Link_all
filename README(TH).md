# PhantomLink - ระบบ Command & Control (C2) และเครื่องมือจัดการระยะไกลขั้นสูง (RAT)

> [!IMPORTANT]
> **ข้อตกลงและคำปฏิเสธความรับผิดชอบเพื่อการศึกษาและการตรวจสอบที่ได้รับอนุญาต**
> ซอฟต์แวร์ในคลังข้อมูล (Repository) นี้ถูกพัฒนาขึ้นเพื่อการวิจัยเชิงการศึกษา การทดสอบเจาะระบบที่ได้รับอนุญาต (Authorized Penetration Testing) และการทำ Red Teaming เท่านั้น 
> การนำไปติดตั้งหรือใช้งานบนระบบคอมพิวเตอร์อื่นโดยไม่ได้รับความยินยอมเป็นลายลักษณ์อักษร ถือเป็นการกระทำที่ผิดกฎหมายทั้งในประเทศและต่างประเทศ ผู้พัฒนาจะไม่รับผิดชอบต่อความเสียหายใดๆ ที่เกิดขึ้นจากการนำเครื่องมือนี้ไปใช้ในทางที่ผิด

PhantomLink คือระบบ Command and Control (C2) และเครื่องมือควบคุมระยะไกล (Remote Administration Tool - RAT) ที่พัฒนาขึ้นด้วยภาษา Python ซึ่งรวมการตรวจสอบความปลอดภัยของระบบ, ระบบมอนิเตอร์และปิดโปรเซสเบื้องหลัง, ระบบอัปเดตไฟล์ Client อัตโนมัติ, การสร้างการเชื่อมต่อกลับแบบถาวร (Persistent Shell), ระบบห้องแชทจำลอง GUI และโมดูลช่วยทดสอบความปลอดภัยเพิ่มเติม เช่น Keylogger, ตัวดักจับภาพหน้าจอ และระบบจำลองการเข้ารหัสไฟล์ (Ransomware Simulator)

## คุณลักษณะเด่นและสถาปัตยกรรมระบบ

### 1. เครื่องมือควบคุมหลัก (C2 Server)
*   **การจัดการไคลเอนต์:** จัดการการเชื่อมต่อผ่าน Socket แบบอะซิงโครนัส พร้อมโปรโตคอลตรวจสอบความยาวข้อมูลเพื่อความปลอดภัย
*   **การวิเคราะห์ Latency:** ตรวจวัดระยะเวลาตอบสนองของเครือข่าย, สถิติคำสั่งสำเร็จ และประมวลผลคะแนนสถานะการเชื่อมต่อแบบเรียลไทม์
*   **การแจ้งเตือนผ่าน Discord:** เชื่อมต่อกับ Discord Webhook เพื่อแจ้งเตือนการเชื่อมต่อของไคลเอนต์และการประมวลผลคำสั่งสำเร็จ (`discord_logger`)
*   **การแจ้งเตือนบนระบบปฏิบัติการ:** ใช้ไลบรารี `notify-py` เพื่อแจ้งเตือนบนหน้าจอ (System Tray) ของฝั่ง C2
*   **การส่งคำสั่งแบบกลุ่ม (Broadcast):** สามารถส่งคำสั่งพร้อมกันไปยังไคลเอนต์ปลายทางเดี่ยว, หลายเครื่อง หรือทุกเครื่องได้

### 2. ไคลเอนต์ปลายทาง (PhantomLink Client)
*   **การเชื่อมต่อกลับแบบคงอยู่ (Persistence):** มีระบบทำงานแบบเธรดเพื่อพยายามเชื่อมต่อใหม่เสมอเมื่อสัญญาณขาดหาย รวมถึงสร้าง Registry คีย์ในพาร์ท `Run` และตั้งการรัน Scheduled Tasks อัตโนมัติ
*   **การรันคำสั่งโดยตรง:** ทำการเรียกใช้งานสคริปต์ Python ในหน่วยความจำ หรือรับคำสั่งรันระบบปฏิบัติการผ่าน Shell
*   **โมดูลเสริมแยกส่วน:** เริ่มต้นการทำงานของ Keylogger และ Screenshoter อิสระในเบื้องหลัง เพื่อดักจับข้อมูลแล้วส่งกลับผ่าน Discord Webhook ที่กำหนดแยก
*   **ระบบอัปเดตตัวเอง (Self-Update):** ดาวน์โหลดเวอร์ชันใหม่ ยุติกระบวนการทำงานเดิม และสลับไปรันไฟล์ใหม่ทันที
*   **การรันโดยไม่มีสิทธิ์แอดมิน (Unprivileged Mode):** หากไม่ได้รับสิทธิ์แอดมิน จะข้ามส่วนที่ต้องใช้สิทธิ์ระบบ (เช่น UAC Bypass, AV Killer) แล้วรันฟังก์ชันหลักต่อได้โดยไม่ขัดข้อง

### 3. การล้างการติดเชื้อ (Anti-Phantom)
*   **การทำความสะอาดระบบ:** ค้นหาคีย์เริ่มต้นระบบที่เป็นอันตรายใน Registry, ลบ Scheduled Tasks, ยุติกระบวนการทำงานของไคลเอนต์, ลบโฟลเดอร์ทำงาน และกู้คืนไฟล์ `hosts` เดิม
*   **การขอสิทธิ์ UAC:** ร้องขอสิทธิ์แอดมินเมื่อเริ่มต้น เพื่อความปลอดภัยในการเข้าถึงและกู้คืนไฟล์ระบบทั้งหมด
*   **การบันทึกรายงาน:** ส่งออกรายละเอียดการล้างระบบไปที่ไฟล์ `PhantomLink_Removal_Report.txt`

## สรุปคำสั่งด่วนที่สำคัญ (Quick Commands)

รายละเอียดทั้งหมดสามารถดูได้ที่ไฟล์ [`Quick Commands.md`](file:///g:/for_hack_all/Link_all/Quick%20Commands.md) โดยคำสั่งหลักๆ ประกอบด้วย:

| หมวดหมู่ | คำสั่ง | คำอธิบาย |
| :--- | :--- | :--- |
| **การจัดการไฟล์** | send / get / harvest | จัดการและดึงไฟล์ข้อมูลจากเป้าหมาย |
| **สื่อและอุปกรณ์** | screenshot / camera / record | บันทึกรูปหน้าจอ ภาพกล้องเว็บแคม หรือเสียงจากไมโครโฟน |
| **ระบบเครือข่าย** | wifi / ip / netscan / worm | ดึงรหัสผ่านไวไฟ ตรวจหา IP หรือแพร่กระจายไฟล์ในวงแลน |
| **ควบคุมระบบ** | disable task manager / sleep / logoff | สั่งจัดการระบบหรือปิดการทำงานของแอปพลิเคชันระบบ |
| **พื้นที่อันตราย** | selfdestruct | ลบตัวไคลเอนต์และล้างไฟล์ทั้งหมดออกจากเครื่องเป้าหมายทันที |

## คำแนะนำการติดตั้งและใช้งาน

### การเปิดใช้งานเครื่องควบคุม (C2 Server)
1. ติดตั้งไลบรารีที่จำเป็น:
   ```bash
   pip install notify-py requests discord.py
   ```
2. ตั้งค่า Discord Webhook ในไฟล์ [`C2/C2.py`](file:///g:/for_hack_all/Link_all/C2/C2.py):
   ```python
   DISCORD_WEBHOOK = "YOUR_DISCORD_WEBHOOK_URL"
   ```
3. รันเซิร์ฟเวอร์ควบคุม:
   ```bash
   python C2/C2.py
   ```

### การสร้างและตั้งค่าตัวไคลเอนต์ (Client)
1. ตั้งค่าที่อยู่ Webhook ในไฟล์ [`client/PhantomLink.py`](file:///g:/for_hack_all/Link_all/client/PhantomLink.py)
2. ทำการคอมไพล์โค้ดเป็นไฟล์เดี่ยว (.exe) ด้วย PyInstaller:
   ```bash
   pyinstaller --onefile --noconsole client/PhantomLink.py
   ```
