# PhantomLink - ระบบ Command & Control (C2) และเครื่องมือจัดการระยะไกลขั้นสูง (RAT)

> [!IMPORTANT]
> **ข้อตกลงและคำปฏิเสธความรับผิดชอบเพื่อการศึกษาและการตรวจสอบที่ได้รับอนุญาต**
> ซอฟต์แวร์ในคลังข้อมูล (Repository) นี้ถูกพัฒนาขึ้นเพื่อการวิจัยเชิงการศึกษา การทดสอบเจาะระบบที่ได้รับอนุญาต (Authorized Penetration Testing) และการทำ Red Teaming เท่านั้น 
> การนำไปติดตั้งหรือใช้งานบนระบบคอมพิวเตอร์อื่นโดยไม่ได้รับความยินยอมเป็นลายลักษณ์อักษร ถือเป็นการกระทำที่ผิดกฎหมายทั้งในประเทศและต่างประเทศ ผู้พัฒนาจะไม่รับผิดชอบต่อความเสียหายใดๆ ที่เกิดขึ้นจากการนำเครื่องมือนี้ไปใช้ในทางที่ผิด

PhantomLink คือโครงสร้างระบบ Command and Control (C2) และเครื่องมือควบคุมระยะไกล (Remote Administration Tool - RAT) ที่พัฒนาขึ้นด้วยภาษา Python ซึ่งรวมคุณลักษณะการหลบหลีกการตรวจจับ (Evasion), ระบบปิดการทำงานของแอนตี้ไวรัสอัตโนมัติ, ระบบอัปเดตไฟล์ Client อัตโนมัติ, การสร้างการเชื่อมต่อกลับแบบถาวร (Persistent Reverse Shell), ระบบห้องแชทจำลอง และโมดูลช่วยทดสอบความปลอดภัยเพิ่มเติม เช่น Keylogger, ตัวดักจับภาพหน้าจอ และระบบจำลองการเข้ารหัสเรียกค่าไถ่ (Ransomware Simulator)

## ⚡ คุณลักษณะเด่นและสถาปัตยกรรมระบบ

### 1. เครื่องมือควบคุมหลัก (C2 Server)
*   **การจัดการหลายไคลเอนต์:** จัดการการเชื่อมต่อผ่าน Socket แบบอะซิงโครนัส พร้อมโปรโตคอลตรวจสอบความยาวข้อมูลและรหัสผ่านเพื่อความปลอดภัย
*   **การวิเคราะห์ Latency & สถานะการเชื่อมต่อ:** ตรวจวัดระยะเวลาตอบสนองของเครือข่าย, สถิติคำสั่งสำเร็จ/ล้มเหลว และประมวลผลคะแนนคุณภาพการเชื่อมต่อแบบเรียลไทม์
*   **การแจ้งเตือนทาง Telegram:** เชื่อมต่อกับ **Telegram Bot** เพื่อแจ้งเตือนทันทีเมื่อมีไคลเอนต์เชื่อมต่อเข้ามาใหม่ (`tel_logger`)
*   **การแจ้งเตือนบนหน้าจอคอมพิวเตอร์:** ใช้ไลบรารี `notify-py` เพื่อแจ้งเตือนบนหน้าจอ (System Tray) ของผู้ควบคุม C2
*   **การควบคุมแบบกลุ่ม:** สามารถส่งคำสั่งพร้อมกันไปยังไคลเอนต์เดียว, หลายเครื่อง หรือทุกเครื่องที่เป็น Botnet ได้

### 2. ไคลเอนต์ปลายทาง (PhantomLink Client)
*   **การเชื่อมต่อกลับอย่างต่อเนื่อง (Persistent Reverse Shell):** มีตรรกะพยายามเชื่อมต่อใหม่เสมอ (Retry-and-reconnect) เมื่อเกิดปัญหาสัญญาณขาดหาย
*   **การรันคำสั่งโดยตรง:** สามารถสั่งการผ่าน Shell (CMD / PowerShell) หรือเรียกใช้งาน Python Scripts ได้ทันที
*   **ระบบอัปเดตตัวเองอัตโนมัติ (Self-Update):** สามารถตรวจสอบเวอร์ชันใหม่ ดาวน์โหลดไฟล์ ดับกระบวนการทำงานที่ทับซ้อนกัน และสลับไปรันไฟล์ใหม่ทันที
*   **ความคงอยู่ของระบบ (Persistence):** ลงทะเบียนในระบบ Windows Startup Registry (Run keys) และสร้าง Scheduled Tasks เพื่อรันตัวเองเมื่อระบบรีสตาร์ท

### 3. การหลบหลีกแอนตี้ไวรัส (AV Bypass & AV Killer)
*   **การปิดการทำงาน Windows Defender:** สั่งปิดการสแกนแบบ Real-time, Behavior Monitoring, IOAV, SmartScreen และปิดการส่งข้อมูลตัวอย่าง โดยใช้คำสั่ง PowerShell ระดับแอดมิน
*   **การตั้งค่าข้อยกเว้น (Exclusions):** เพิ่มไดเรกทอรีการทำงานหลัก (เช่น `%APPDATA%\MicrosoftUpdate`) ลงในข้อยกเว้นของ Windows Defender เพื่อป้องกันการลบไฟล์
*   **ระบบมอนิเตอร์เพื่อยุติแอนตี้ไวรัส (AV Killer):** รันเธรดเบื้องหลังสแกนทุกๆ 30 วินาทีเพื่อบังคับปิดโปรเซสของซอฟต์แวร์แอนตี้ไวรัสหลัก (เช่น Avast, AVG, Avira, McAfee, Malwarebytes)
*   **การทำความสะอาดไฟล์บันทึกกิจกรรม:** สั่งล้าง Event Logs ของระบบ (`Application`, `Security`, `System`, และ `PowerShell`) เพื่อลบร่องรอย

### 4. เครื่องมือล้างการติดเชื้อ (Anti-Phantom)
*   **การทำความสะอาดระบบ:** ค้นหาคีย์เริ่มต้นระบบที่เป็นอันตรายใน Registry, ลบ Scheduled Tasks ของระบบ, ปิดโปรเซสแปลกปลอมที่เชื่อมโยงกับ PhantomLink (`defender.exe`, `client.exe`, `keylogger.exe`) และกู้คืนไฟล์ `hosts` เดิมของเครื่องกลับมา
*   **การขอสิทธิ์ผู้ดูแลระบบ:** ร้องขอสิทธิ์ UAC (Administrator Privileges) ทันทีที่รัน เพื่อให้แน่ใจว่าลบไฟล์และคีย์ระบบได้ครบถ้วน
*   **การเขียนรายงาน:** ส่งออกบันทึกการทำงานในชื่อไฟล์ `PhantomLink_Removal_Report.txt` เพื่อแสดงรายการที่ได้รับการกู้คืนทั้งหมด

### 5. โมดูลเครื่องมือเสริมอื่นๆ (`more-tools/`)
*   **Spyware (Keylogger & Screenshoter):** ไฟล์ดักจับคีย์บอร์ดหรือภาพหน้าจอตามรอบเวลา จากนั้นส่งข้อมูลออกไปยัง Telegram ของผู้ดูแลระบบโดยตรง
*   **โปรแกรมจำลอง Ransomware (`its_your_ransom.py`):** เข้ารหัสลับแบบสมมาตรโดยใช้ `cryptography.fernet` เพื่อล็อกไฟล์เอกสาร รูปภาพ วิดีโอในโฟลเดอร์ผู้ใช้ (Desktop, Documents, Downloads ฯลฯ) รวมถึงไดรฟ์ภายนอก มีหน้าต่างอินเทอร์เฟซ GUI แจ้งเตือน และระบบปลดล็อกเมื่อใส่คีย์ที่ถูกต้อง

## 🛠️ คำแนะนำการติดตั้งและใช้งาน

### การเปิดใช้งานเครื่องควบคุม (C2 Server)
1. ติดตั้งไลบรารีที่จำเป็นก่อนเริ่มต้น:
   ```bash
   pip install notify-py requests
   ```
2. ตั้งค่า Telegram ID ในไฟล์ [`C2/C2.py`](file:///g:/for_hack_all/Link_all/C2/C2.py):
   ```python
   CHAT_ID = "ใส่_CHAT_ID_ของคุณ"
   # ตั้งค่า Bot Token ในฟังก์ชันการส่งข้อมูลตามลำดับ
   ```
3. รันเซิร์ฟเวอร์ควบคุม:
   ```bash
   python C2/C2.py
   ```

### การตั้งค่าและสร้างไฟล์ไคลเอนต์ (Client)
1. อัปเดต `BOT_TOKEN` และ `CHAT_ID` ในไฟล์ [`client/PhantomLink.py`](file:///g:/for_hack_all/Link_all/client/PhantomLink.py)
2. แปลงโค้ด Python ให้เป็นไฟล์ตัวรัน (.exe) ด้วย PyInstaller (ถ้าต้องการ):
   ```bash
   pyinstaller --onefile --noconsole client/PhantomLink.py
   ```

### การล้างการทำงาน (Disinfection)
เมื่อทดสอบเจาะระบบจำลองเสร็จสิ้นและต้องการนำไฟล์และคีย์ทั้งหมดออก:
1. รันไฟล์ [`Anti-Phantom/Anti-Phantom.py`](file:///g:/for_hack_all/Link_all/Anti-Phantom/Anti-Phantom.py) ด้วยสิทธิ์ผู้ดูแลระบบ (Run as Administrator):
   ```bash
   python Anti-Phantom/Anti-Phantom.py
   ```
2. ตรวจสอบรายละเอียดการทำความสะอาดระบบในไฟล์ `PhantomLink_Removal_Report.txt` ที่สร้างขึ้น
